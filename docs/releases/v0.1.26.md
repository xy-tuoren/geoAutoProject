# v0.1.26

- 新增豆包 APP 批量采集：核对原题、展开参考资料、验证长图接缝并记录失败现场。
- 支持按平台完成全部问题，或每道题完成全部平台；平台优先级可通过上下箭头调整。继续与重试沿用原批次计划。
- 采集顺序使用一行文字加切换图标，平台列表改为紧凑单行。
- 屏幕总览支持点击、拖动、长按、滚轮、返回、主页、最近任务及文字输入，采集中也可操作。手动操作涉及的成功题标记为“建议核图”。
- ADB 设备查询增加超时容限、一次只读重试、并发查询合并和详细错误信息。
- 搜索入口只扫描稳定首屏，使用独立加载预算，避免重复 OCR 和沿用回答生成等待时间。
- 修复小程序回顶与原题定位、引用展开、药品入口及图片完整性判断；补充药品抽屉清理前的失败证据。
- 支持经已验证头条入口跳转到小荷 APP 后采集原题回答。

交付与调试目录契约为版本 11。正式截图仍使用 ADB 原始 PNG，手动控制通过独立 uiautomator2 sidecar，视频预览不用于正式交付。

按用户要求，本次未新增本地 UI 或真机验收；发布使用仓库既有 Windows CI 的 Python 测试、Node 检查、安装包构建及更新源验证。
